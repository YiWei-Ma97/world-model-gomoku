# 和模型下一盘 · 手机版五子棋

手机浏览器直接玩，支持纯神经／神经＋推理两种模式。默认15×15，可选17×17与19×19。
黑棋先行，五子及以上连线胜，无禁手。支持执黑/执白、悔棋、保存棋谱与刷新续局。

本仓库仅发布游戏前端、浏览器推理运行包和0.53.5已训练模型的必要推理权重。
不包含模型核心Python源代码、训练代码、完整数据库、优化器、训练记录或原项目Git历史。
ONNX文件含计算图与权重，浏览器运行包和模型资产可下载、分析；发布不构成算法保密。
浏览器运行包不提供源映射或原始推理实现文件；压缩不等同防逆向。

两种模式沿用同一实际训练模型。纯神经模式不调用世界模型；组合模式额外执行已学世界
程序进行有界两步推演。游戏裁判仅判断真实胜负，不给模型提供专家选点。
模型仍有局限，局部测试不意味着对局必胜。全部计算在浏览器执行，无登录、无遥测、
无棋局上传，也不会自动使用本局训练。首次加载约12MB，缓存后可离线继续。

## 发布Pages

在本仓库 Settings → Pages → Build and deployment 中选择 Deploy from a branch，
分支 main，目录 / (root)，保存后等待GitHub显示实际发布网址。无需后台服务。
